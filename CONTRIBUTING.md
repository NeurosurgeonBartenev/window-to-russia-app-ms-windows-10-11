# Contributing to Window to RUSSIA

Thank you for your interest in contributing to Window to RUSSIA! This document provides guidelines and instructions for contributing.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your feature/fix
4. Make your changes
5. Commit and push
6. Create a Pull Request

## Development Setup

```bash
git clone https://github.com/YOUR_USERNAME/WINDOW-to-RUSSIA-APP-MS-WINDOWS-10-11.git
cd WINDOW-to-RUSSIA-APP-MS-WINDOWS-10-11
npm run install-all
```

## Code Style

- Use TypeScript for frontend and desktop code
- Use Python with PEP 8 style for backend
- Follow existing code patterns
- Write meaningful commit messages

## Testing

Before submitting a PR:
- Write tests for new features
- Ensure all tests pass: `npm run test`
- Check code quality: `npm run lint`

## Pull Request Process

1. Update documentation as needed
2. Add tests for new features
3. Ensure CI/CD passes
4. Request review from maintainers

## Reporting Issues

When reporting bugs:
- Describe the issue clearly
- Provide steps to reproduce
- Include screenshots if applicable
- Mention your OS and app version

## Questions?

Open an issue or start a discussion in the repository.
